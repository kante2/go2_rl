# DiffImpact: 착지 한 번당 소음 예측

강화학습 보상에 쓰기 위해, Go2 트롯 보행에서 **착지 한 번(대각 두 발 한 세트)마다 나는 소리**를 로봇 상태로 예측하는 모델입니다. DiffImpact(Clarke et al., CoRL 2021)의 미분 가능한 충격음 합성 구조를 바탕으로 했습니다. 학습은 실로봇 녹음으로 하고, 적용은 MuJoCo 착지 상태로 합니다.

## 현재 모델

`runs/w100_200hz_kin_grf_s{0,1,2}/model_feat.pt`: 시드 3개, 레벨 보정 적용. 세 모델의 예측을 파워 평균하는 **앙상블로 쓰는 것을 권장**합니다.

| 설정 | 값 |
|---|---|
| 창 | 세트 첫 착지 기준 -20 ~ +80 ms |
| 로봇 상태 | 실로봇 lowstate를 200 Hz로 줄여 사용 (MuJoCo 물리 스텝과 같은 시각 해상도) |
| 입력 (착지마다 13개) | 착지 직전 10 ms 발 속도 vx·vy·vz·크기, 착지 순간 발 위치 x·y·z, 속도 명령 vx·vy·wz, 토크 기반 접촉력(착지 후 20 ms 상승폭·충격량, 로그), 세트 안 두 번째 발 여부 |
| 출력 | 착지 소리 파형(결정적 충격음 + 확률적 충격음 + 배경소음). 보상에는 착지 후 0~40 ms 레벨 [dBFS] |

검증은 학습에 쓰지 않은 녹화 4개(세트 106개)로 했습니다. 직진 0.7 v6, 직진 0.5 v3, 횡방향 v4, 회전 v5입니다.

| 지표 | 단일 모델 (시드 3개 평균 ± 표준편차) | 3개 앙상블 |
|---|---|---|
| 착지 후 0~40 ms 레벨 MAE | 1.43 ± 0.09 dB | **1.23 dB** |
| 편향 | -0.19 ± 0.29 dB | -0.10 dB |
| 상관 (세트별) | 0.84 | 0.87 |
| 0~80 ms 대역 MAE (50–200 / 200–1k / 1–4k / 4–12k Hz) | 2.2 / 1.7 / 1.3 / 1.6 dB | |
| 시뮬 착지에 적용: 녹화별 중앙값 레벨과 실측의 상관 | 0.73 | 0.73 |
| 시뮬 착지에 적용: 편향 | -0.55 ± 1.40 dB | -0.15 dB |

상세 수치는 `runs/compare/current.csv`, `levelcal.csv`에 있습니다. 실행별 `metrics.json`의 spectral·band·post40 항목은 레벨 보정 전 값이고, 보정 후 값은 `calibrated_eval`에 있습니다.

## 재현

`src/diffimpact/`에서 실행합니다. 입력은 `src/sim_to_real_data/{real_sim, real_sim_straight}`입니다.

```bash
# 배경소음·모터 소음용 300 ms 창 (실로봇 원본 500 Hz)
python3 extract_touchdowns.py --pre 0.05 --post 0.25 --real-rate 0 --out data/touchdown_w300_500hz --plots
python3 make_pairs.py --dir data/touchdown_w300_500hz
python3 extract_motor_noise.py

# 학습용 100 ms 창, 실로봇 200 Hz (기본값)
python3 extract_touchdowns.py
python3 make_pairs.py

# 학습 (시드마다 약 2분, RTX 2060). 끝에 레벨 보정이 자동 적용됨
for s in 0 1 2; do python3 train_diffimpact.py --seed $s --out runs/w100_200hz_kin_grf_s$s; done

# 평가·그림
python3 compare_runs.py runs/w100_200hz_kin_grf_s0 runs/w100_200hz_kin_grf_s1 runs/w100_200hz_kin_grf_s2 --name current
python3 plot_waveforms.py; python3 plot_stream_prediction.py; python3 plot_timing_analysis.py
```

## 데이터

**녹화:** 같은 RL 보행 정책(model_34997)을 실로봇과 MuJoCo에서 동시에 실행한 기록 20개입니다.
- 직진: real_sim_straight 9개 + real_sim NORMAL_01·04
- 횡방향: NORMAL_0.5_0.5_v1~v4
- 제자리 회전: NORMAL_0.5_0.5_0.5_v1~v5
- NORMAL_07: 보행 없이 서 있다 엎드린 기록이라 착지가 없음 → 모터 소음 데이터로만 사용

보행 종류는 폴더 이름이 아니라 실제 명령으로 분류했습니다. `real_sim`의 NORMAL_01·04는 직진입니다.

**착지 검출:** 발 센서 `ls_ff`를 다리별로 히스테리시스로 판정합니다.
- 공중 기준값 `air`: 실로봇은 파일·다리별 5 백분위수, 시뮬은 고정값 (8, 10, 12, 9)
- 접지 판정: `air + 10`을 넘으면 접지, `air + 4` 아래면 공중
- 유효 조건: 착지 전 60 ms 이상 공중, 착지 후 40 ms 이상 접지
- 착지 시각: 힘이 `air + 2`를 넘어 오르기 시작한 첫 샘플. 시계는 PC monotonic(실로봇·시뮬 공통)
- 결과: 실로봇 착지 1108개 → 세트 543개, 시뮬 착지 934개 → 세트 464개

**대각 쌍 세트:** 80 ms 안의 착지를 한 묶음으로 보고, 그중 대각 두 발이 정확히 한 번씩 닿은 것만 씁니다. 두 발 간격 중앙값은 실로봇 12 ms, 시뮬 15 ms입니다.

**200 Hz:** 실로봇 lowstate를 5 ms 틱마다 그 시점의 최신 값으로 줄입니다(sample-and-hold, MuJoCo와 같음). 특징 값은 500 Hz와 거의 같지만(상관 0.95~0.98), 착지 시각이 평균 2.4 ms 늦게 잡힙니다. 이 조건으로 학습해야 MuJoCo에 적용할 때 시각이 맞습니다. 소리는 48 kHz 그대로입니다.

**토크 기반 접촉력:** 다리마다 F = −J(q)⁻ᵀ·τ로 계산하고(URDF 야코비안, `ls_tau`), 중력 정렬 좌표로 돌립니다.
- 실로봇과 시뮬에 같은 식을 써서 단위[N]가 같습니다. 발 센서 `ls_ff`는 실로봇·시뮬 크기가 달라 입력에서 뺐습니다.
- 시뮬 정답(`sim_foot_force_vec`)과 비교하면 입각기 수직력 차이는 약 2 N, 시계열 상관은 0.86~0.92, 착지별 20 ms 상승폭 상관은 0.86입니다.
- 접촉 순간의 짧은 충격 스파이크는 PD 토크에 다 드러나지 않습니다. 10 ms 상승률은 정답과 무관해서 쓰지 않습니다.

## 모델

```
소리(t) = Σ_i [펄스_i * 모달응답_leg] * 공간응답        결정적 충격음 (원 DiffImpact)
        + Σ_i A_i · 확률적 충격음_leg(t − t_i)          착지가 일으키는 위상이 랜덤한 소리 (추가)
        + 배경소음                                       측정값으로 고정
```

| 구성 요소 | 설명 |
|---|---|
| 펄스 | Hertz형 sin^1.5, 면적 = 충격 크기 A_i. 시각 = 착지 검출 시각 + 다리별 지연(학습) |
| 모달 응답 | 감쇠 사인파 64개. 주파수·감쇠는 공유, 이득은 다리별 |
| 공간 응답 | δ + 50 ms 학습 꼬리 |
| 확률적 충격음 | 기대 파워 = A_i²·g_leg·S(f)·e(t − t_i). 결정적 성분과 같은 A를 공유해서, 착지가 세면 둘 다 커짐 |
| 배경소음 | 1 kHz 위는 NORMAL_07 모터 소음(서 있음 + 모터 꺼짐), 아래는 보행 중 착지 전 구간(-50 ~ -10 ms)으로 측정해 고정 |
| 손실 | 확률적 성분을 기대 파워로 더하고, STFT 파워(128~1024)를 로그 간격 대역(40 Hz~20 kHz, 옥타브당 6개)으로 합산한 뒤 Itakura-Saito 발산(지수분포 우도)으로 비교 |

**학습 순서**
1. **식별:** 세트별 충격 크기와 시각 미세조정(±8 ms)을 자유 파라미터로 두고 공통 파라미터를 맞춥니다.
2. **예측:** 충격 크기를 착지 특징의 다리별 로그선형 함수로 학습합니다.
3. **레벨 보정:** 학습 세트의 착지 후 0~40 ms 예측 레벨 평균 편향이 0이 되도록 공통 상수 하나를 조정합니다. IS 손실이 과대 예측 쪽으로 치우치는데 그 정도가 시드마다 달라서(+0.9 ~ +2.3 dB) 넣었습니다. 착지 간 상대 크기는 바뀌지 않습니다.

**평가 지표:** 확률적 성분은 위상이 랜덤이라 파형을 직접 비교하지 않습니다.
- **레벨:** 실측 한 번의 실현값과 같은 통계가 되도록, 예측에도 소음을 8번 샘플링해 더한 뒤 dB를 평균합니다.
- **시뮬 적용:** 시뮬 착지로 예측한 녹화별 중앙값 레벨을 같은 녹화의 실측 중앙값과 비교합니다(보행 위상이 달라 착지끼리는 짝지을 수 없음).

**모터 소음 (NORMAL_07):** 서서 자세를 유지할 때 모터 소음은 모터가 꺼졌을 때와 1 kHz 위에서 구분되지 않습니다. 3, 8, 17 kHz 부근 톤은 모터가 꺼져도 남아 있습니다. 보행 중에는 50–150 Hz가 +8 ~ +14 dB 커서, 1 kHz 아래는 보행 중 구간으로 소음을 정했습니다. 결과는 `data/motor_noise/noise_spectra.png`, `band_levels.csv`에 있습니다.

**실로봇 vs 시뮬 착지 차이** (`figures/timing_analysis.png`)
- **착지 순서:** 직진에서 실로봇은 앞발이 먼저(84%), 시뮬은 뒷발이 먼저(62%) 닿습니다. 순서 자체는 소리에 거의 영향이 없습니다(0.3 dB 미만).
- **두 발 간격:** 실로봇에서 같은 녹화 안이라도 동시에 닿을수록 큽니다(간격 10 ms 미만 +1 dB, 30 ms 이상 -2.8 dB).
- **발 하강 속도:** 시뮬은 일부 조건에서 발이 더 빨리 내려옵니다(직진 0.7 뒷발 -1.06 vs 실로봇 -0.72 m/s). 실로봇은 녹화별로 발이 빨리 내려올수록 소리가 큽니다(0.1 m/s당 약 1.4 dB).
- **좌우 비대칭:** 시뮬은 두 대각 쌍의 착지 세기가 번갈아 크게 다릅니다(`figures/stream_prediction.png`).

## 남은 과제

- **보상 레벨 정의:** A-가중(dBFS(A))으로 바꾸고 그 기준으로 보정합니다. A-가중 자체에는 캘리브레이션 파일이 필요 없습니다. 마이크 주파수 응답 보정과 절대 dB SPL에는 `src/db_collector/7208479*.txt`(UMIK-1, 0° / 90°)를 씁니다.
- **강화학습용 착지별 소음 예측 함수:** 시뮬 착지 상태 → 3개 앙상블 레벨
- **동시 착지 효과의 방향:** 시뮬 착지를 동시로 바꾸면 모델은 -0.6 dB로 예측해, 실측(+0.9 dB)과 반대입니다. "두 번째 발 여부" 특징의 영향으로 추정합니다.
- **소리 시작 시각:** 모델 소리가 실측보다 약 5 ms 일찍 시작합니다.
- **입각기 소리 (착지 후 80 ms 이후):** 예측하지 않습니다. 착지당 보상이 목적이라 범위에서 뺐습니다.
