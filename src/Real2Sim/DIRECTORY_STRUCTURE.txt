Real2Sim directory structure

Analysis: scripts/real2sim/run_converter.sh -> pipeline.py
Viewer:   replay/run_replay.sh -> serve.py (read-only; no rebuild)
Full documentation: README.md

data/
  real/<dataset>/*_real.npz
  sim/<dataset>/*_sim.npz
scripts/
  real2sim/
    config.py, pipeline.py, preprocessing.py, time_alignment.py
    deployment_mapping.py, deployment_normalization.json
    metrics.py, reporting.py, dataset_summary.py, storage.py, export_ui.py
    plot_mapping.py, plot_torque.py, analyze_time_delay.py
    run_converter.sh
    tests/
    legacy/  (historical reconstruction and physics replay)
  compare_tau.py  (plot saved torque)
  collect_sim_baseline.py, run_collect_sim_baseline.sh
  compare_real_sim.py, phase_synchronization.py  (older standalone analysis)
  offline_identification/  (separate experimental workflow)
result/<dataset>/
  manifest.json
  processed/*_mapping.npz
  metrics/<trial>.json, mapping_summary.json, metrics.csv
  analysis.md
  figures/mapping/
  figures/torque/
  ui/index.json, <trial>.json
  diagnostics/<trial>/  (optional)
result/<dataset>_real_sim_analysis.txt  (updated with the default analysis)
replay/
  run_replay.sh, serve.py
  web/index.html, app.js, chart.js, style.css
  tests/
reference/
simulator/  (optional baseline collection)

Raw data and generated result contents stay local; source and docs are versioned.
